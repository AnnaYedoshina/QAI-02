# Проект автоматизации тестирования для SauceDemo

Этот проект представляет собой полноценный каркас для автоматизации тестирования веб-приложения [https://www.saucedemo.com/](https://www.saucedemo.com/).

## Описание

Проект реализован на языке **Java** с использованием **Selenium WebDriver** для взаимодействия с браузером. В качестве фреймворка для тестирования используется **TestNG**, а для управления зависимостями и сборкой — **Maven**. Для генерации подробных отчетов о тестировании интегрирована система **Allure**.

Архитектура проекта построена на паттерне **PageObject Model (POM)**, что обеспечивает высокую читаемость, переиспользуемость и простоту поддержки тестов.

## Технический стек

- **Язык**: Java 11
- **Сборка**: Maven
- **Тестовый фреймворк**: TestNG
- **UI-автоматизация**: Selenium WebDriver
- **Паттерн проектирования**: PageObject Model
- **Отчетность**: Allure Report
- **Управление драйверами**: WebDriverManager

## Структура проекта

```
.
├── pom.xml                     # Файл Maven с зависимостями и конфигурацией сборки
├── README.md                   # Этот файл
├── testng.xml                  # Конфигурация для запуска тестов TestNG
└── src
    └── test
        └── java
            └── com
                └── saucedemo
                    ├── pages/              # Директория для классов PageObject
                    │   ├── CartPage.java
                    │   ├── CheckoutCompletePage.java
                    │   ├── CheckoutStepOnePage.java
                    │   ├── CheckoutStepTwoPage.java
                    │   ├── LoginPage.java
                    │   └── ProductsPage.java
                    └── tests/              # Директория для тестовых классов
                        ├── BaseTest.java   # Базовый класс с @Before/@After методами
                        └── E2ETest.java    # End-to-End тест
```

- **`pom.xml`**: Определяет все необходимые зависимости (Selenium, TestNG, Allure, AssertJ, WebDriverManager) и плагины (maven-surefire-plugin для запуска тестов, allure-maven для генерации отчета).
- **`src/test/java/com/saucedemo/pages`**: Содержит классы, реализующие паттерн PageObject. Каждый класс соответствует определенной странице приложения и инкапсулирует логику поиска элементов и взаимодействия с ними.
- **`src/test/java/com/saucedemo/tests`**: Содержит тестовые классы.
  - **`BaseTest.java`**: Абстрактный базовый класс, который отвечает за инициализацию (`@BeforeMethod`) и закрытие (`@AfterMethod`) экземпляра `WebDriver` для каждого теста.
  - **`E2ETest.java`**: Содержит end-to-end тест, который имитирует полный путь пользователя.
- **`testng.xml`**: Файл конфигурации TestNG, который определяет, какие тесты должны быть выполнены.

## Покрытый E2E-сценарий

Тест `fullE2EScenarioTest` в классе `E2ETest` выполняет следующий сценарий:
1.  **Логин**: Открывает сайт и выполняет вход с учетными данными `standard_user`.
2.  **Добавление товара**: Находит товар "Sauce Labs Backpack" и добавляет его в корзину.
3.  **Переход в корзину**: Открывает корзину и проверяет, что товар добавлен.
4.  **Удаление товара**: Удаляет товар из корзины и проверяет, что корзина пуста.
5.  **Возврат в каталог**: Нажимает "Continue Shopping" и возвращается на страницу с товарами.
6.  **Добавление другого товара**: Находит товар "Sauce Labs Bike Light" и добавляет его в корзину.
7.  **Оформление заказа**: Переходит к процедуре оформления заказа.
8.  **Ввод данных**: Заполняет форму с данными покупателя (имя, фамилия, почтовый индекс).
9.  **Подтверждение заказа**: Завершает оформление, нажимая "Finish".
10. **Проверка результата**: Убеждается, что заказ успешно оформлен, проверяя наличие сообщения "Thank you for your order!".

## Установка и запуск

### Требования
-   Java (JDK) 11 или выше
-   Apache Maven
-   Google Chrome (для выполнения тестов)

### Установка зависимостей
Проект использует Maven, все зависимости будут загружены автоматически. Откройте проект в вашей IDE и дождитесь, пока Maven разрешит все зависимости. Или выполните команду в терминале:

```bash
mvn clean install
```

### Запуск тестов
Для запуска тестов выполните следующую команду в корневой директории проекта:

```bash
mvn test
```
Maven запустит тесты, определенные в файле `testng.xml`, используя `maven-surefire-plugin`.

### Генерация и просмотр Allure-отчета
После выполнения тестов будут сгенерированы `allure-results`. Чтобы сгенерировать HTML-отчет и открыть его в браузере, выполните команду:

```bash
mvn allure:serve
```
Эта команда сгенерирует отчет и запустит локальный веб-сервер, после чего откроет отчет в вашем браузере по умолчанию.
